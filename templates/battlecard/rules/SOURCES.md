# Where facts for a battlecard live

Use a search result only to find the primary page.

| Fact | Best source | Notes |
|---|---|---|
| Legal entity, HQ | Each company's footer, terms or imprint | SEC EDGAR or the national registry for public companies |
| Positioning, segments | Homepage, product pages, case studies, logos | Its own words: cite as its claim |
| Competitor's "vs" pages | The competitor's site | Marketing. It says nothing reliable about your company |
| Pricing | The pricing page; plan-limit docs | "Contact sales" stays "contact sales" |
| Price history | The Wayback Machine: web.archive.org/web/<YYYY>/<url> | Read two copies and give both dates |
| Marketplace pricing | AWS Marketplace, Azure Marketplace, Google Cloud Marketplace listings | Label as indirect if it differs from the site |
| Capabilities | Product docs, API references, integration directories, changelogs | Release notes carry dates |
| Security and compliance | The trust or security page; a named report (SOC 2, ISO 27001) | A badge on a page is a claim until the report or registry confirms it |
| Reviews | G2, Capterra, TrustRadius, Gartner Peer Insights | Record count and date range |
| Community | Reddit, Hacker News, vendor forums, GitHub issues | Patterns only: never quote one post as a trend |
| Reliability | The status page and its incident history | Count incidents in a stated window |
| Moves | Press releases, wire services, trade press, job posts | Event date and publication date |

## Reading reviews well

- "Recurring" means several independent reports of the same problem. Give the count and the date range.
- Reviews labeled as incentivized, or posted by the vendor, are noted as such.
- A review about a different product or a same-name company is dropped.
- Quote under 25 words, exactly.

## What a seller can repeat

Prices as published with the date seen; capabilities as documented; incidents as the status page logs them; reviews as
counts and short quotes. Anything else is inference, labeled so, or left out.
