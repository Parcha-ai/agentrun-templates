# What the tracker counts

The competitor-content skill reads this before every edition. Edit it like code. What the owner tells the agent later
is kept in its learning and wins over this file where they differ.

## A piece

Public output dated inside the window, seen on the rival's own archive (blog index, channel video tab, podcast feed,
newsletter archive, resources or events page): an article, report, webinar, video, short, live stream, episode, issue
or case study. A piece dated before the window is not this week's, even if it is still on top of the page. Paywalled,
login-only or private material is not read; say so in `unreachable`.

## Metrics

- Only what the page shows: views, likes, comments, chart rank, review count, shares. Write it with the date you read it:
  "19,400 views as of 2026-11-16". Counts change; a bare number is wrong.
- Never a subscriber count, open rate, download number or revenue unless the page states it; a third-party estimate is
  labeled as an estimate with its source.
- An **outperformer** beats that rival's own recent baseline (for example the median of its last ten pieces on the same
  page). State the baseline and how you worked it out. Never rank rivals against each other on raw numbers.

## Sponsors

Named only when visible: a labeled ad, a spoken ad read in a description, a disclosed partner, a co-host logo on a
webinar page, or the sponsor's own announcement. An affiliate link you suspect is "inferred".

## Gaps

A gap is a topic, format or question your evidence shows demand for and no listed rival served in the window. It needs
a source showing demand: a busy thread or forum post asking for it, a rival piece whose comments ask for more, a
rising chart or search signal. "Nobody wrote about X" alone is not a gap.

## People

Guests and staff appear only as the outlet credits them. Commenters are paraphrased, never named.
